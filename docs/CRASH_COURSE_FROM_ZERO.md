# 2. Design Thinking — zero se samjho

**Design Thinking**
- *English: A human-centred way of solving problems, starting with the person rather than the technology (Brown, 2008).*
- **Hinglish:** Design Thinking matlab insaan se shuru karke problem solve karna — technology se nahi. Iske **paanch stages** hain. Aage-peechhe ja sakte hain, ye koi seedhi seedhi ladder nahi hai.

| Stage | Matlab | Humne kya kiya |
|---|---|---|
| **1. Empathise** | User ki zindagi aur feel samjho | 25 responses ka questionnaire, open answers code kiye, empathy map aur persona banaya |
| **2. Define** | Gando ko ek clear problem banao | POV, HMW, MoSCoW, descriptive statistics |
| **3. Ideate** | Bahut saare solutions nikalo | 10 ideas, mind map, SWOT, weighted matrix |
| **4. Prototype** | Sasta aur rough version banao | Chrome extension + responsive Flask dashboard + SQLite |
| **5. Test** | Users par try karo aur maapo | Teen timed tasks, click/error logging, 10-item SUS form, hypothesis tests |

## Professor ke terms — pehle English, phir Hinglish

- **Double diamond**
  - *English: The process diverges and converges twice — first in the problem space, then in the solution space.*
  - **Hinglish:** Do baar phailna aur do baar simitna — pehle problem ke andar, phir solution ke andar. Questionnaire→persona pehla diamond, 10-ideas→matrix dosra.
- **Empathy map**
  - *English: A four-quadrant summary — Says, Thinks, Does, Feels — built from real user responses.*
  - **Hinglish:** Chaar hisson ka chart — bolta kya hai, sochta kya hai, karta kya hai, feel karta kya hai. Hamare mein ads, repetitive recommendations aur saving nikal ke aaya.
- **Persona**
  - *English: One invented but realistic archetype representing the typical user.*
  - **Hinglish:** Ek banaya hua par realistic kirdaar jo typical user ko represent kare. Hamara hai **Aarav, 19** — B.Tech student, roz Spotify, save karta hai par wapas nahi dekhta.
- **POV (Point of View)**
  - *English: A one-sentence problem statement of the form "[user] who [struggle] needs [solution] because [insight]."*
  - **Hinglish:** Ek line ka problem statement. Hamara: roz sunne wala insaan jo save karke wapas nahi dhoondh paata, aur feel karta hai ki recommendations sirf "thode se" match karte hain — use familiarity control aur mood se retrieval chahiye, kyunki discovery app ke bahar hoti hai aur saved collection dhoondhna mushkil hai.
- **HMW (How Might We)**
  - *English: An open question that invites solutions, not a yes/no question.*
  - **Hinglish:** Aisa khula sawaal jiska uttar solution nikale, haan/naa mein na ho. Hamara: *"Hum kaise listeners ko recommendations ki familiarity par control dein aur saved gaane mood se wapas dhoondhne dein — bina paid subscription ya naye account ke?"*
- **MoSCoW**
  - *English: Must / Should / Could / Won't prioritisation.*
  - **Hinglish:** Must = Discover, My Music, backend. Won't = ads hatana, offline downloads.
- **SWOT**
  - *English: Strengths, Weaknesses, Opportunities, Threats — a check on the chosen idea.*
  - **Hinglish:** Strengths, Weaknesses, Opportunities, Threats — chune gaye idea ko fragile selectors aur chhote sample ke khilaaf check karne ke liye.
- **Weighted selection matrix**
  - *English: Score each idea 1–5 on desirability (40%), feasibility (35%) and viability (25%), multiply by weights and add.*
  - **Hinglish:** Har idea ko 1–5 par do cheezon se score karo — desirable Kitna hai, feasible kitna hai, viable kitna hai — weights se multiply karke jodo. **10 ideas**, teen ka score **5.00** (slider, vibe tags, library). Ad blocker **2.80** — reject, kyunki feasible nahi.

# 3. Research methodology — zero se

## Sampling

**Convenience sampling**
- *English: Using whoever was easy to reach rather than a random sample.*
- **Hinglish:** Jo aasani se mil gaya — yahan students. Random nahi. Isliye sab music listeners par daava nahi kar sakte; limitation batana padega. **25 responses**, brief ka target **30** tha.

## Questionnaire ke sawaal

| Type | Example | Kyun zaroori |
|---|---|---|
| Multiple choice | "Kaunsa platform sabse zyada?" | Saaf counts aur percentage |
| **Ordinal** | "Easy / Average / Difficult" | Order hai, par gaps barabar nahi |
| Numeric | "Age" | Mean, median, spread nikal sakte hain |
| Open-ended | "Sabse badi problem kya?" | Real quotes aur themes |

**Ordinal data**
- *English: Ordered categories where the gaps between values are not equal.*
- **Hinglish:** Answers ka order hai (Easy > Average > Difficult), par Easy se Average ka gap utna nahi jitna Average se Difficult ka. Isi liye Pearson se zyada Spearman safe hai.

## Answers ko numbers mein kaise badla

- **3** = positive: Easy / Very well / Daily
- **2** = middle: Average / Somewhat / Several times a week
- **1** = negative: Difficult / Poorly / Occasionally / Sometimes difficult

**Neutral = 2.** Ye "2" har t-test ka comparison point hai.

## Ethics

**Ethics**
- *English: Informed consent, anonymisation, no fabrication and disclosure of AI use.*
- **Hinglish:** Participants ko bataya gaya, participation voluntary tha, naam **R01–R25** se replace kiye, koi contact detail nahi li, AI tools ka istemal bataya gaya. Do low-quality responses **flag kiye, delete nahi**. Koi data nahi ghadha.

# 4. Statistics — zero se sabse important section

Professor sabse zyada yahin ghot te hain. Pehle ideas, phir numbers.

## 4.1 Mean, median, standard deviation

- **Mean**
  - *English: The average — add all values and divide by the count.*
  - **Hinglish:** Mean matlab average — saare values jodo, count se divide karo.
- **Median**
  - *English: The middle value after sorting the data.*
  - **Hinglish:** Sort karne ke baad beech wala value.
- **Standard deviation (SD)**
  - *English: The typical distance of values from the mean; small SD means similar answers, large SD means spread-out answers.*
  - **Hinglish:** Mean se values ki doori ka andaza. Kam SD = sab ne similar jawab diya; zyada SD = jawab phaile hue.

Hamari umar: range **18–30**, median **19**, numeric mean **19.76**, SD **2.44**.

## 4.2 One-sample t-test

**One-sample t-test**
- *English: A test that checks whether a sample mean differs from a known value — here, the neutral value 2.*
- **Hinglish:** Test jo dekhta hai ki hamara mean kisi pakke number se alag hai ya nahi — yahan wala number hai 2 (neutral). Har measure ke liye ek test.

- **t**
  - *English: How far the mean is from 2, measured in standard errors; larger |t| means stronger evidence.*
  - **Hinglish:** Mean 2 se kitni door hai, standard errors mein naap kar. |t| bada = mazboot evidence.
- **p-value**
  - *English: If there were no real difference, the probability of seeing data this extreme.*
  - **Hinglish:** Agar asal mein koi farq hi na ho, toh itna extreme data milne ki probability kitni? Chhota p (0.05 se kam) = ye mushkil hai = result **significant**.
- **Statistically significant**
  - *English: Unlikely to be due to chance, based on a threshold chosen before testing.*
  - **Hinglish:** Hajaron mein nahi, sirf chance se hona mushkil — pehle se tay kiye gaye threshold par.
- **alpha = 0.05**
  - *English: The significance threshold fixed before testing.*
  - **Hinglish:** Pehle se tay kiya gate — 0.05 se kam p mila to significant.
- **95% confidence interval (CI)**
  - *English: A range of plausible values for the true mean; if it excludes 2, that agrees with p < 0.05.*
  - **Hinglish:** Asli mean ke liye sambhavit range. Agar isme 2 nahi hai, to ye p < 0.05 se match karta hai.
- **df = 24**
  - *English: Degrees of freedom = n − 1 = 25 − 1.*
  - **Hinglish:** Degrees of freedom = n − 1 = 25 − 1 = 24.

### Chaar results — pair mein yaad karo

| Measure | Mean | SD | t | p | 95% CI | Matlab |
|---|---|---|---|---|---|---|
| Usage frequency | **2.48** | 0.77 | 3.116 | **0.0047** | [2.16, 2.80] | neutral se upar |
| Vibe-finding ease | **2.48** | 0.65 | 3.674 | **0.0012** | [2.21, 2.75] | neutral se upar |
| Saved retrieval | **2.12** | 1.01 | 0.592 | **0.5593** | [1.70, 2.54] | **significant nahi** |
| Taste understanding | **2.40** | 0.65 | 3.098 | **0.0049** | [2.13, 2.67] | neutral se upar |

**Interpretation — shabd shabd mein:**
> "Vibe-finding ease aur taste understanding neutral se significantly upar hain,
> saved retrieval nahi. Ye results ye nahi kehte ki users bahut naakush hain.
> Ye ek chhota daava karte hain: personalisation *achha hai par zabardast nahi*,
> aur retrieval friction itna aam hai ki isko solve karna padega."

**"Good-but-not-great baseline"** — ye phrase baar baar bolo. Kabhi mat bolo ki
users "broken" hain — data uski support nahi karta.

## 4.3 Correlation

**Correlation**
- *English: A number describing the direction and strength of a relationship between two variables.*
- **Hinglish:** Do cheezon ke rishte ki disha aur mazbooti batane wala number.

- **r / rho (ρ)**
  - *English: Ranges from −1 to +1. Positive = both rise together; negative = one rises as the other falls. Roughly, 0.1 weak, 0.3 moderate, 0.5+ strong.*
  - **Hinglish:** −1 se +1 tak. + matlab dono saath badhte hain; − matlab ek badhe to doosra ghire. 0.1 kamzor, 0.3 thoda, 0.5+ mazboot.
- **Pearson**
  - *English: Correlation on raw values, assuming a straight-line relationship.*
  - **Hinglish:** Sachche values par correlation, seedhi line ke assumption ke saath.
- **Spearman**
  - *English: Correlation on ranks rather than raw values — safer for ordinal data and small samples.*
  - **Hinglish:** Values ki jagah ranks par correlation — ordinal data aur chhote sample ke liye zyada safe. Hum dono batate hain, bharosa Spearman par karte hain.
- **Critical |r| at n=25 ≈ 0.396**
  - *English: The minimum coefficient needed for significance at alpha 0.05 with n=25.*
  - **Hinglish:** n=25 par significant hone ke liye coefficient kam se kam 0.396 hona chahiye.

### Hamare correlations

| Pair | Pearson | Spearman | p | Matlab |
|---|---|---|---|---|
| Vibe ease ↔ saved retrieval | +0.413 | +0.393 | 0.0522 | thoda sa miss |
| Vibe ease ↔ taste | +0.415 | +0.334 | 0.1027 | kamzor, directional |
| **Saved retrieval ↔ taste** | +0.433 | **+0.417** | **0.0380** | **akela significant pair** |
| Usage frequency ↔ taste | +0.101 | +0.166 | 0.4280 | kamzor |

**Sawdhani wala jawab:**
> "n=25 par critical value 0.396 hai. Sirf saved retrieval aur taste isse cross
> karte hain — 0.417, p = 0.038. Chhota sample aur kai comparisons ki wajah se
> main isse directional evidence maanta hoon, causation nahi bolta."

**Correlation is not causation** — ye hamesha bolo agar poocha jaye.

## 4.4 Hypotheses (test se PEHLE tay kiye)

| | Daava |
|---|---|
| **H1a** | Prototype ke saath save kiya gaana dhoondhne ka median time **kam** hai |
| **H0a** | Retrieval time mein koi farq nahi |
| **H1b** | Discovery use karne ke baad taste rating **2.40 se upar** hai |
| **H0b** | 2.40 se koi badlaav nahi |
| **H1c** | Mean SUS score **68 se upar** hai |
| **H0c** | SUS 68 ya usse kam hai |

- **H0 (null)**
  - *English: The claim that nothing happens.*
  - **Hinglish:** "Kuch nahi hota" wala-default daava.
- **H1 (alternative)**
  - *English: The claim that something does happen.*
  - **Hinglish:** "Kuch hota hai" wala daava.
- **Paired design**
  - *English: The same participants try both methods, so each person is their own control.*
  - **Hinglish:** Ek hi participant dono tareeke try karta hai — har insaan khud ka control ban jata hai.
- **Wilcoxon signed-rank**
  - *English: A non-parametric test used for paired differences when normality is doubtful.*
  - **Hinglish:** Paired time ke liye test, jab difference normal na lage.
- **Paired t-test**
  - *English: The paired test used when the difference is approximately normal.*
  - **Hinglish:** Paired test jab difference normal jaisa ho.
- **Effect size**
  - *English: How big the improvement is, not merely whether it is detectable.*
  - **Hinglish:** Sudhaar kitna bada hai — sirf "detect ho gaya" nahi. Mean difference bhi batana padega.

# 6. Website — zero se

## 6.1 Page kholne par kya hota hai

1. Tum URL likhote ho, jaise `http://127.0.0.1:5000/discover`.
2. Browser **server** ko **HTTP request** bhejta hai (yahan Flask, tumhare hi
   computer par chal raha hai).
3. Server ek function chalata hai aur **HTTP response** mein **HTML** wapas
   bhejta hai.
4. Browser HTML dikhata hai; **CSS** usse sundar banata hai, **JavaScript**
   interactive banata hai.

**HTTP request**
- *English: A message sent by the browser to the server asking for a page or sending data.*
- **Hinglish:** Browser se server ko bheja gaya sandesh — page maangna ya data bhejna.

**GET vs POST**
- *English: GET asks for a page and puts data in the URL; POST sends data in the request body.*
- **Hinglish:** GET page maangta hai aur data URL mein daalta hai (`?level=familiar&platform=Spotify`). POST data body mein bhejta hai — forms aur save ke liye.

## 6.2 HTML, CSS, JavaScript ka role

- **HTML**
  - *English: The structure and content of a page — headings, buttons, forms, tables.*
  - **Hinglish:** Page ki haddi aur content — heading, button, form, table.
- **CSS**
  - *English: The appearance — colours, spacing, layout and mobile rules.*
  - **Hinglish:** Dikhaav aur decoration — rang, spacing, layout, mobile rules.
- **JavaScript**
  - *English: The behaviour — reacting to clicks, talking to the server, updating the page.*
  - **Hinglish:** Vyavhaar — click par karna, server se baat karna, page update karna.

## 6.3 Flask aur routes

**Flask**
- *English: A small Python web framework that maps URLs to functions and returns web pages.*
- **Hinglish:** Chhota Python framework jo URL ko function se jodta hai aur page wapas deta hai.

**Decorator**
- *English: A line like `@app.route("/discover")` that tells Flask which URL runs the function below it.*
- **Hinglish:** `@app.route("/discover")` jaisi line jo Flask ko batati hai — ye URL aaye to neeche wala function chalao.

| URL | Function | Kya hota hai |
|---|---|---|
| `/` | `index()` | `saved_songs` padho, 3 counts dikhao |
| `/discover` | `discover()` | URL se `?platform=` aur `?level=` padho, recommendations nikalo |
| `/vibe` | `vibe()` | `?vibe=` padho, mood Recommendations |
| `/preferences` | `preferences()` | GET form dikhao, POST save karo |
| `/study` | `study()` | Purane tasks aur SUS form |
| `/results` | `results()` | CSV padho, stats gino, charts dikhao |
| `/api/save` | `api_save()` | JSON API: saved song insert |
| `/api/unsave/<id>` | `api_unsave()` | JSON API: saved song delete |
| `/api/event` | `api_event()` | JSON API: click/task/SUS event log |
| `/api/task` | `api_task()` | JSON API: poori hui timed task store |
| `/api/summary` | `api_summary()` | Database ke raw counts |
| `/health` | `health()` | Server zinda hai? CSV hai? |

`request.args.get("level")` URL ke values padhta hai; `request.form.get(...)` POST
form ke; `request.get_json()` woh JSON jo JavaScript ne bheja.

**render_template**
- *English: Fills a Jinja template with variables and returns the finished HTML.*
- **Hinglish:** Jinja template mein variables bhar kar tayyar HTML wapas deta hai.

## 6.4 Jinja templates

**Jinja**
- *English: The template language that lets Python values appear inside HTML.*
- **Hinglish:** Template language jo Python ki values HTML mein dikhata hai.

- `{{ variable }}` — value print karta hai.
- `{% for x in items %}` — loop; `{% if saved %}` — condition.
- `{% extends "base.html" %}` + `{% block content %}` — saare pages ek hi
  header/nav/footer share karte hain, beech ka hissa badalta hai.
- **url_for**
  - *English: Builds a URL from a function name instead of hard-coding it.*
  - **Hinglish:** URL ko hard-code karne ki jagah function ke naam se banata hai.

## 6.5 SQLite aur paanch tables

**SQLite**
- *English: A database stored in a single file (`webapp/pme.db`).*
- **Hinglish:** Database jo ek hi file mein hoti hai — `webapp/pme.db`.

**Table**
- *English: Like a spreadsheet — rows are records, columns are fields.*
- **Hinglish:** Spreadsheet jaisa — row = record, column = field.

| Table | Kya store karta hai |
|---|---|
| `users` | Browser ka anonymous ID (cookie se) — naam nahi, login nahi |
| `saved_songs` | title, artist, genre, reason, source |
| `preferences` | default level, pasandida vibe, tracking consent |
| `usage_events` | event type aur detail — har view, save, task start |
| `test_tasks` | task naam, duration, clicks, errors, completed |

**SQL** ke shabd: `SELECT` (padho), `INSERT` (jodo), `UPDATE` (badlo),
`DELETE` (hatao), `WHERE` (filter), `UNIQUE` (duplicate nahi), `FOREIGN KEY`
(row doosre table ki real row se juda hai), `INDEX` (teez dhoondhna).

**Upsert**
- *English: Try UPDATE; if no row changed, INSERT a new one.*
- **Hinglish:** Pehle UPDATE karne ki koshish; agar koi row na badle to INSERT kar do.

## 6.6 Cookie

**Cookie**
- *English: A small value stored in the browser that identifies the same visitor on repeat visits.*
- **Hinglish:** Browser mein chhota sa value jo baar-baar aane par ek hi visitor ko pehchanta hai.

`pme_session` ek random ID hai. Isse server bina login aur bina naam ke ek hi
browser ko pehchanta hai — anonymity bhi bachti hai aur measurement bhi hota hai.

## 6.7 Ek click ko end-to-end follow karo (bahut probable sawaal)

**"User ne recommendation par Save dabaya":**

1. HTML button mein `data-title`, `data-artist`, `data-genre`, `data-reason`,
   `data-source` hote hain — gaane ki details.
2. `app.js` click sunta hai, unhe `button.dataset.title` wagairah mein padhta hai.
3. `postJSON('/api/save', song)` unhe `fetch()` se JSON mein bhejta hai.
4. Flask ka `api_save()` JSON padhta hai, title aur artist check karta hai.
5. `INSERT OR IGNORE INTO saved_songs ...` chalata hai — SQLite row jodta hai.
6. `usage_events` mein `save_song` event log karta hai.
7. `{"ok": true}` wapas bhejta hai; JavaScript button ko "Saved ✓" kar deta hai.

**"User ne /discover khola":** Flask URL values padhta hai → `recommendations.py`
mein `get_recommendations(platform, level, artist)` chalata hai → wo demo
dictionary se picks nikalta hai → Flask check karta hai kaunse pehle se saved
hain → `discover_view` event log karta hai → `discover.html` render karta hai.

**SUS scoring**
- *English: Odd items contribute (answer − 1), even items (5 − answer); sum × 2.5 gives 0–100, with 68 as the benchmark.*
- **Hinglish:** Odd sawalon par (answer − 1), even par (5 − answer). Inka jod × 2.5 = 0–100 score. **68** benchmark hai.

## 6.9 CSS vocabulary

**CSS variable**
- *English: A reusable value defined as `--green` and used with `var(--green)`.*
- **Hinglish:** Ek reusable value — `:root { --green: #1DB954; }` mein define, `var(--green)` se istemal.

`display: flex` cheezon ko ek line mein, `display: grid` rows aur columns mein

## 6.10 Chrome extension (website se alag)

**Content script**
- *English: JavaScript injected into a web page to modify or read that page.*
- **Hinglish:** JS jo web page mein inject hoke us page ko padhta ya badalta hai — yahan Spotify/YouTube Music/Apple Music par side panel add karta hai.

**Adapter**
- *English: A small platform-specific piece that checks `window.location.hostname` and finds the current track.*
- **Hinglish:** Har platform ka chhota hissa jo hostname dekh kar decide karta hai ki lagoo hai ya nahi, aur current track dhoondhta hai.

**Polling**
- *English: Repeatedly checking for a value at fixed intervals — here every 2 seconds.*
- **Hinglish:** Har 2 second par baar-baar check karna. `MutationObserver` se isliye behtar kyunki ye single-page apps DOM ko tod kar dobara banati hain, jisse observer toot jata hai.

`chrome.storage` client par data rakhta hai; SQLite dashboard aur measurement ke
liye. Agar site ka layout badle to sirf uska adapter fix karna padega — ye
limitation hai.

# 7. Pressure mein kisi bhi sawaal ka jawab kaise do

Chaaran hisson ka structure — ye tumhe shant aur pakka lagne deta hai:

1. **Seedha jawab pehle** — ek line.
2. **Evidence** — number, file ya stage.
3. **Kyun** — wajah.
4. **Limitation** — ek imaandaar caveat.

Example: *"Haan, ek correlation significant hai (1). Retrieval aur taste 0.417,
p = 0.038 (2). Maine Spearman isliye kiya kyunki data ordinal hai aur n chhota
hai (3). Par 25 responses aur kai comparisons ki wajah se main isse directional
maanta hoon, causal nahi (4)."*

**Agar sach mein pata na ho:** bolo *"Is detail ka mujhe pura yakeen nahi —
check karne ki jagah ___ hogi."* Number kabhi mat ghado. Imandaar "pata nahi"
se kam nuksaan hota hai galat number se.

**Time lene wale shabd:** "Isko do hisson mein samjhata hoon…" / "Chhota jawab
hai…, aur wajah ye hai…"
